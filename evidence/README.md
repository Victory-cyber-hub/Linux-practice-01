# Evidence

The original Linux task does not explicitly require screenshots. This folder is provided as an organized place to keep evidence if your instructor/class requires or benefits from it.

## Suggested Screenshots

These are documentation suggestions, not invented requirements from the original task.

### `01-user-created.png`

Show evidence that `student01` exists and, after switching, that:

```bash
whoami
```

returns `student01`.

Do not show the password.

### `02-workspace-created.png`

Show:

```bash
ls -la ~/project
```

and the expected `docs`, `scripts`, and `bin` directories.

### `03-files-created.png`

Show the relevant `ls -la` output and/or file contents demonstrating the created files.

### `04-permissions.png`

Show the final permission listings for:

- `scripts/install.sh`
- `bin/classified.txt`

If you created `admin_notes.txt`, capture its permissions before deleting it if your instructor wants evidence of that step.

### `05-final-directory-structure.png`

Show:

```bash
tree project
```

after the activity is complete.
